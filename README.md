# منصة أعمال فروع الهيئة السعودية للمياه

نسخة تفاعلية مطورة وفق المتطلبات المعتمدة لإدارة الطلبات ومتابعة معاملات تراسل والتحديثات الأسبوعية والشهرية، مع الحفاظ على هوية الهيئة ونمط تصميم المنصات الحكومية.

تشمل النسخة:

- الطلبات الواردة من مكتب وكيل الفروع.
- الطلبات الداخلية والطلبات المتبادلة بين الفروع مع عزل البيانات.
- متابعة معاملات تراسل يدويًا في قسم مستقل؛ ونظام تراسل هو المصدر الرسمي.
- تحديثات موثقة وتاريخ كامل للإجراءات.
- قائمة ولوحة تدفق وتقويم وفلاتر موحدة.
- تحديثات أسبوعية وشهرية منشأة من الأعمال المسجلة.
- تصدير Excel وإرسال التقرير بالبريد المؤسسي.
- أدوار وصلاحيات تفصل الإشراف عن التشغيل وإدارة المنصة.

## تشغيلها على جهازك

يتطلب الجهاز Node.js 22 أو أحدث، ثم نفّذ:

```bash
npm install
npm run dev
```

## نشرها على GitHub Pages

1. أنشئ مستودعًا جديدًا في GitHub بالاسم الذي تريده، مثل `swa-work-hub`.
2. ارفع محتويات هذا المجلد كاملة إلى الفرع `main`.
3. من إعدادات المستودع افتح `Settings > Pages`.
4. اجعل مصدر النشر `GitHub Actions`.
5. سيعمل النشر تلقائيًا، ويصبح الرابط بالشكل:

```text
https://USERNAME.github.io/REPOSITORY/
```

يتغير `USERNAME` حسب اسم حسابك، ويتغير `REPOSITORY` حسب اسم المستودع. ويمكن إضافة نطاق مخصص لاحقًا من إعدادات GitHub Pages.

هذه نسخة تفاعلية ببيانات تجريبية. متابعة تراسل في هذه المرحلة يدوية ولا يوجد تكامل آلي. الربط الفعلي مع تراسل ومنصة الزيارات والدخول الموحد والبريد المؤسسي وقاعدة البيانات يحتاج مرحلة تطوير خلفية مستقلة.
